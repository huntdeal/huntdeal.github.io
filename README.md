# HuntDeal v2 — Amazon-readiness content build

This is a static GitHub Pages starter focused on original editorial content and buying education.

Before publishing:
- Replace/update the public contact details on `contact.html`.
- Review the legal pages against the services actually enabled.
- Do not publish fabricated prices, discounts, reviews, sales counts or retailer claims.
- Do not claim to be an Amazon Associate until accepted.
- When an affiliate program is enabled, add its required disclosure and compliant links.
- For Amazon, follow the current Associates Operating Agreement and current linking/product-data rules.

This build intentionally has no fake/demo deals and no Amazon API integration.
